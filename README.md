# 上岸计划 · 成人高考专升本个人备考系统

“上岸计划”是一套面向成人高考专升本考生的个人备考系统。它把报考信息整理、院校查询、入学诊断、目标分分析、学习计划和阶段复习串成一条完整流程，帮助考生从“应该报什么、当前水平如何”逐步走到“今天具体学什么”。

> 当前为河南、江苏公开数据试运行版，使用 2025 年公开数据提供 2026 年备考规划参考。院校、专业和录取要求以当年教育考试院及院校招生简章为准，本系统不构成录取承诺。

## 项目解决什么问题

成人专升本备考的信息通常分散在考试院公告、院校文件和个人笔记中，考生很难快速回答下面这些问题：

- 我的专业属于哪个报考科类，需要考哪些科目？
- 有哪些院校可以选择，往年参考线是多少？
- 我目前各科大概处于什么水平，薄弱知识点在哪里？
- 目标总分应该如何分配到每个科目？
- 距离考试还有一段时间，每天应该完成什么任务？
- 阶段测试出错后，后续计划应该怎样调整？

本项目将这些问题集中到一个账号体系中，并持续保存用户的报考档案、诊断结果和学习进度。

## 核心功能

### 报考档案

按省份、城市和专业整理个人报考信息，自动关联报考科类、考试科目与学习模式，为后续院校查询和学习计划提供基础。

### 专业与院校

根据省级教育考试院公开数据查询相关院校、专业计划和参考分数，并标记数据来源与可信度，帮助考生整理选择范围。

### 入学诊断

使用分科题库进行基础诊断，自动计算各科预估分、知识点掌握度和薄弱项，形成个人能力起点。

### 目标分分析

结合公开参考线、诊断结果和安全空间生成总分目标，并把目标分合理分配到各考试科目。

### 学习路线

根据考试日期、学习模式和薄弱项生成分阶段计划、每日任务与里程碑，让备考目标落到每天可以执行的任务上。

### 阶段测试与动态纠偏

记录阶段测试结果，把错题对应的知识点加入复习队列；当学习进度落后时，系统会调整后续任务和阶段安排。

### 账号与进度同步

新用户需要通过 Cloudflare Turnstile 人机验证，并使用 Resend 发送的六位邮箱验证码完成注册。登录后，报考档案、诊断结果、学习计划和完成进度会保存在服务端，方便在不同设备上继续学习。

#### 邮箱注册配置

1. 在 Resend 验证发信域名并创建 API Key，将 `exam-study-hub-server/.env.example` 中的 `RESEND_API_KEY` 和 `RESEND_FROM_EMAIL` 写入后端 `.env`。
2. 在 Cloudflare Turnstile 创建站点，将 Secret Key 写入后端 `.env` 的 `TURNSTILE_SECRET_KEY`。
3. 将 Turnstile Site Key 写入前端 `.env` 的 `VITE_TURNSTILE_SITE_KEY`，参考 `exam-study-hub-client/.env.example`。
4. 在 `exam-study-hub-server` 目录执行 `alembic upgrade head`，创建验证码记录表和邮箱验证时间字段。

验证码默认 10 分钟过期，同一邮箱 60 秒内不能重发、24 小时内最多发送 5 次，同一 IP 每小时最多发送 20 次，连续输错 5 次后失效。这些数值均可通过后端环境变量调整。

### 管理员后台

管理员可以维护用户与角色、查看用户填报信息、重置用户密码，并检查院校数据覆盖、导入批次、题库质量和基础数据。

## 使用流程

```text
登录或注册
  → 建立报考档案
  → 查询专业与院校
  → 完成入学诊断
  → 生成目标分分析
  → 制定分阶段学习路线
  → 执行每日任务
  → 参加阶段测试
  → 根据结果动态纠偏
```

## 当前数据范围

- 江苏：主要使用 2025 年教育考试院公开的院校投档线。
- 河南：使用近三年专升本省控线，以及 2025 年成人高招录取征集志愿计划等公开资料。
- 浙江：已抓取 2023—2025 年教育考试院公开的成人高考专升本省控线；院校专业生源计划和征求计划需登录报名系统查询，暂未作为可选报考省份开放。
- 题库：覆盖当前已接入的考试科目与知识点，用于学习诊断和阶段测试。

需要注意：成人高考并不统一公布逐专业录取线；征集志愿备档线也不等同于主批次院校投档线。因此，系统中的分数和院校信息用于缩小选择范围与制定备考目标，不能替代官方招生信息。

## 项目定位

这是一个个人学习与非商业备考项目，重点是帮助考生整理公开信息、认识自身水平并形成可执行的学习计划，不提供录取预测或录取承诺。
