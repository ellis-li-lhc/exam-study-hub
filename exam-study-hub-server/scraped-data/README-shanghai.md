跨年份、批次合计40所院校、679条记录。另外收录2023—2025年每年8个科类的市控线，共24条。2025各校计划人数均与官方表中的校级总计核对；0人记录原样保留，2026未公布人数保存为null。

`sources/shanghai/`保存3份完整PDF及3份控制线网页，`shanghai-manifest.json`记录来源URL、SHA-256和数量；`shanghai-adult-programs.json`包含来源页码、专业方向、外语语种、学制与最低学习年限、学费原文、学习形式、教学点编号和解析后的地点、招生范围与备注。院校代码是上海招生代码，不等于其他省份或国标代码。

## 入库与适配

```bash
python -m scripts.scrape_shanghai          # 从已缓存官方文件重新解析、校验
python -m scripts.scrape_shanghai --refresh # 重新下载官方来源
python -m scripts.seed_shanghai            # 事务导入，仅操作上海资料，可重复运行
python -m scripts.validate_data
```

完整初始化`scripts.seed`也会调用上海导入器。需要先执行项目已有迁移`alembic upgrade head`，本次无新增表或迁移。计划字段沿用`admission_plans`；额外目录字段保存在院校`supplemental_data.plan_details`，接口按年份/批次/专业代码还原；市控线独立存于`province_control_scores`。

- 未取得院校实际录取线，`admission_scores`没有为上海写入任何记录。市控线在页面单独标注，不作为院校分数、录取概率或提分目标；2026市控线尚未收录。
- 2026为当前目录，院校匹配只使用该年正式专业目录；2025主批次/征求记录仍可查看，但不作为今年开设专业的证据。
- 保留既有66个专业主数据；全部来源中43个专业名称可对应现有主数据，56个名称尚未配置课程，完整原始专业记录已入库。2026有31所院校可匹配系统现有专业。
- 目录的日语考试记录保留，但当前系统备考课程仅支持英语，不将仅考日语的专业提供为上海备考目标。显示实际外语语种、委托培养范围、加试及学分备注供核对。
- 235条按学分收费记录保留收费原文，不折算年费；444条按年/学年收费保留原口径。解析器也支持保留小数学分单价而不取整。学制和最低学习年限分开显示，不把最低学习年限当作名义学制。
- 城市筛选按院校所在地；上海教学点地址在专业计划内单独显示，省外院校通过“省外院校”偏好筛选。

PDF解析移除大字号水印字符；对上海电机学院2025目录跨第7—8页的合并院校单元格，读取原始左栏文字恢复归属，避免把28条记录错误归入上一所院校。解析器对未知行、未解析教学点、重复专业代码和学校计划合计不一致直接报错，不静默跳过。
