另接入2025普通统考专升本省控线8条，来自[宜春学院终身教育学院转载的省教育考试院公告](https://ycxycj.jxycu.edu.cn/2025/1205/c271a147915/page.psp)。分别是文史中医135、艺术110、理工100、经济管理100、法学121、教育110、农学105、医学150分。原公告另列的“一村一名大学生工程”专项不导入普通省控线，也不混入当前普通备考目标。暂无院校实际录取线及已核实的征集明细，暂无2027目录，2026资料仅作2027备考历史参考。

2026年11月6日再次访问省级报名系统，HTTP 503页面明确提示“该系统目前处于维护状态”，原始响应保存在 `sources/jiangxi/portal-maintenance-2026-11-06.html`；因此尚未取得全省目录，不能把14校称为江西院校总数。未公布招生人数及具体专业教学点保留null。江西理工大学和江西水利电力大学原文公布的专业教学点逐条保留；后者明确排除5个省外教学点，不以省外计划替代江西计划。江西师大“心理学”、赣南师大“应用心理学、地理科学、生物科学”按原文经管类处理，不根据“理学”学位门类误推为理工。赣南师大使用简章中明确公布的专业代码及科类表，并交叉核对考试科目；只提取专升本，排除高起本和专科。南昌航空大学双栏目录分别解析，共30条，不能只读取左半表。

院校采用教育部2026学校标识码、校本部城市。江西师大保留国家专业代码，赣南师大保留简章招生专业代码；江西农业和南昌航空大学未公布专业代码，使用 `catalog-` 内部键保证可重复入库，API保留 `major_code_raw=null`，页面显示“未公布”，不伪造官方代码。赣南师大明确英语科目，其余未指定语种的记录保留未知。

沿用现有 `admission_plans`、`province_control_scores`、`institutions` 表，不新增表。与现有学习课程专业名称和科类均匹配的院校专业才作为学习目标。抓取、事务导入、校验命令见 `README-hunan.md`；主初始化脚本也会导入两省。原始页面和校验哈希见 `sources/jiangxi/`、`jiangxi-manifest.json`。这批数据尚未推送部署至远程生产环境。

补充来源的URL和原始HTML/PDF/图片均在 `sources/jiangxi/source-urls.json`。新余学院图片提取记录、南昌大学PDF数字与合并末行的目视核对记录保存为 `brochure-*-2026-reviewed.json`，绑定原件SHA-256；重新下载原件一旦变化，抓取器会要求重新核验，避免沿用过期人工提取。
