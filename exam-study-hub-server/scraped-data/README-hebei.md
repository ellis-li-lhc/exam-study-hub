## 身份、科类与费用

- 河北院校编号会随年份变化。按完整院校名称核对跨年身份，使用最新已取得年度的编号关联入库；历史独有院校增加年份前缀。比如2024院校146是河北医科大学，2025的146是河北外国语学院；医科大学两年记录归入系统关联码147，但2024原始编号146完整保留。
- 2024渤海大学与2025大连海事大学都曾使用306，因此分别关联到`2024-306`及`306`。页面展示每条计划的当年原始编号。系统关联码不能替代当年官方填报代码。
- 目标匹配仅使用2025计划；2024独有院校保留历史记录，不作为2025开设专业的证据。页面明确标注“2025年计划参考”，未称为2026招生目录。
- 保留既有66个专业和考试科目。全部来源中54个专业名称能对应现有主数据，另111个名称完整保留；考虑考试科类兼容后，2025有77所院校、475个院校与专业组合可作目标参考。
- 2025的6条应用心理学计划属于经管科类，而现有系统主数据将其配置在教育学类；这些记录保留入库，暂不开放为河北备考目标。2024网络与新媒体艺术类记录也保留其真实科类，不套用文史课程。未因此修改其他省份或全局专业主数据。
- 2023—2025普通统考线与2024—2025农民工考生专项线按数据库`round`分开保存、在页面分区展示。文史与中医按真实专业分别匹配。省控线不会写入院校分数表，也不用于生成院校提分目标。
- 1709条计划均有费用和办学地点原文：1597条按年/学年收费，104条标明总学费或完整2.5年学费，8条只给出物价部门核定等说明。保留原文，不把8000元/2.5年折算成年费。解析器支持小数年费原文，不强行写入整数金额。
- 限农民工、铁路职工、钢铁企业职工、在职人民警察等条件及加试说明按原表保存；2024函授/业余及2025非脱产分别保留，不改写历史学习形式。
- 院校所在地主要来自教育部2026高校名册，并对开放大学、保定校区及历史院校采用相应官方地址来源。所在地用于城市偏好；各专业办学地点另行展示。防灾科技学院与华北科技学院按2024—2025来源中的独立院校身份保留，未用后来的合并名称重写历史招生记录。

## 导入与复核

先执行已有迁移`alembic upgrade head`，本次没有新增表或迁移。

```bash
python -m scripts.scrape_hebei            # 使用缓存的完整官方来源重新解析
python -m scripts.scrape_hebei --refresh  # 重新下载原始来源
python -m scripts.seed_hebei             # 河北范围事务导入，可重复运行
python -m scripts.validate_data
python -m unittest tests.test_hebei
```

完整初始化`scripts.seed`也会调用河北导入器。主字段使用现有`admission_plans`，附加说明保存在`supplemental_data.plan_details`；原始院校编号、适用人群及页码经接口提供给页面。前端选择值增加`hebei:`前缀，避免与其他省份同码，既有省份选择值不变。

PDF按字符坐标恢复跨行单元格，并与完整PDF中按文字科类识别出的独立记录数交叉核对：885/824。收费栏从字符恢复，避免把相邻的学费粘进办学地点；长院校名称及跨页备注均已核对。未知行、未知学习形式、缺失关键列、跨年身份冲突或重复代码会中止解析。原表没有提供可独立核对的各校总计，表中人数合计是已提取记录之和。
