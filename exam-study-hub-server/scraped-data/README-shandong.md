## 字段与匹配

- 目录保留8位省编院校专业代号及国标专业代码；征集表的3位院校代码加5位专业代码与当年目录逐项关联。来源中的代码原文、工作表名及行号均保留，三个批次不会互相覆盖。
- 科类名称同时保留来源原文和用于匹配的统一名称。文史与中医分开匹配省控线：2025年文史130分、中医120分。2023/2024体育单列，2025采用教育学类合并行，不复制出不存在的体育行。
- 保留“职业本科”及附带说明的完整专业名称，不将其当作同名普通本科。限民警、辅警、在职消防救援人员等报考条件、直属或委培范围及原表加试提醒保留供核对。
- 当前目标仅根据2026目录匹配，2025目录及征集记录作为历史资料。89所院校中，76所在2026目录能匹配系统已有课程，共629个院校与专业组合。既有66个专业主数据没有变更；全部来源中59个名称可匹配，另163个不同名称（含职业本科附注的不同写法）完整入库，未擅自配置课程或考试科目。
- 同一院校的2025来源名称保留在结构化源记录中，院校主记录使用最新目录名称，例如2025“滨州医学院”与2026“山东医药大学”按山东招生代码114关联。
- 院校所在地按教育部名册匹配，不是山东教学点地址。山东医药大学按名册登记为滨州；两所开放大学及华北电力大学保定校区使用相应官方地址。各校城市来源见`shandong-institution-cities.json`。
- 目录未提供学费、教学点、外语语种或最低修业年限，相应字段保留未知；公布的2.5或3年学制可直接显示。未将名义学制复制为最低修业年限。
- 未收录院校实际录取线及2026省控线。29条省控线独立存入`province_control_scores`，不会写入`admission_scores`，也不会用于推算院校提分目标。
- 前端为新接入的山东选择值加`shandong:`前缀以避免跨省同码；数据库、来源文件及接口中的官方院校代码不变，既有省份保存的选择值不变。

## 导入与复核

先执行已有数据库迁移`alembic upgrade head`，本次无新增表或迁移。

```bash
python -m scripts.scrape_shandong            # 使用已缓存的完整官方来源解析
python -m scripts.scrape_shandong --refresh  # 重新下载，并校验控制线图片哈希
python -m scripts.seed_shandong             # 事务导入，仅操作山东，支持重复运行
python -m scripts.validate_data
python -m unittest tests.test_shandong
```

完整初始化`scripts.seed`也会调用山东导入器。主字段使用现有`admission_plans`，目录附加字段按年份/批次/专业代码保存在院校`supplemental_data.plan_details`并经院校接口返回。全部原表数据行均计入专升本记录或排除层次统计；未知层次、表头变化、重复代码、征集无法匹配目录、控制线图片变化都会中止抓取，避免静默漏行。
