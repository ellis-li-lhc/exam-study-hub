# 四川成人高考专升本资料

2026-11-06接入；2026目录为2027备考历史参考，不代表2027招生安排。8月初次目录归档49所院校、1329条记录，去重为406个院校专业组合；当前11月二次计划已另行接入，见文末审查修正。同名专业因教学点不同重复出现，不可把记录数当作专业数或人数。

官方目录：https://www.sceea.cn/Html/202608/Newsdetail_4951_5.html 。已下载该专升本页全部55张图片，不含高起本、高起专。保留院校3位代码、专业6位代码（含前导零）、考试科类、学制、收费原文、学习形式、教学点名称、地址和招生限制。院校所在地按教育部2026普通高校名单及四川开放大学官网核验，不把教学点所在地当作校本部所在地。

原始图片、4组OCR结果及`catalog-reviewed-2026.json`在`sources/sichuan/`。提取过程：独立识别物理网格共1329行；全图、分列、逐行识别交叉比对核心字段；右侧教学点/地址逐行复核；对111处识别冲突或疑义文字查看官方原图，校正值及页、行、列保存在`manual_review`。网格元数据另有归档。校验院校代码与专业代码前缀、代码唯一性、科类与考试码一致性。图片、OCR与人工核验文件均由SHA-256绑定；图片变化时拒绝沿用旧提取结果。

10条限定招生记录（7条铁路单位职工、3条在职消防救援人员）保留原文，`selection_eligible=false`，不作普通备考目标。未公布招生人数，`plan_count=null`；总学费不转成年学费，外语未在目录列明时保留为空。2024、2025普通统考专升本省控线各8条单列，排除高起本、高起专及其他试点分数。暂无院校实际录取线。

在服务端目录执行：

```sh
.venv/bin/python -m scripts.scrape_sichuan_chongqing
.venv/bin/python -m scripts.seed_sichuan_chongqing
.venv/bin/python -m scripts.validate_data
```

默认从归档重放并核对来源哈希；`--refresh`重新读取公开官方源，源图片变化后需重新识别并人工核验，不能直接复用旧校对值。导入仅操作两个地区、单事务、可重复运行，不需要新增表或迁移。

原始图片识别工具在`scripts/sichuan_ocr/`，仅重做图片识别时需要macOS Vision/Swift及Pillow：先运行`full.swift 图片列表`和`grid.py`生成网格，再运行`columns.swift`、`rows.swift`、`right_rows.swift`，后3个参数为图片目录和`grid-metadata.json`。识别结果须经过上述比对和冲突复核，禁止直接作为已核实数据入库。

## 2026-11-06审查修正

当前已补入[2026年11月5日第二次公布的专升本计划](https://www.sceea.cn/Html/202611/NewsDetail_5012_4.html)：49校1240条、49031人，10条限定招生记录不作普通目标。最新原文为13列HTML表格，可逐行核对，无需OCR；`sichuan-adult-current-plans.json`与`sichuan-current-manifest.json`单列归档。8月1329条目录继续保存，数据库共2569条不同批次记录；当前匹配按`active_catalog_round`只采用第二次公布，旧目录中未进入新计划的89个专业代码不能混入当前目标和学费预览。新计划数是官方2026计划，不是实际录取人数或2027计划。

官方二次表中不足6位的专业代号保留在`major_code_raw`；内部`major_code`补前导零用于跨版本关联，不改变原文展示。两个批次分别保存人数空值与公开人数，不把新人数回填到旧目录。
