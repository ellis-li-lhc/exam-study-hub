## 数据口径

- `hubei-adult-programs.json` 是专业目录，人数未知保持 `null`，不能作为人数计划。
- `hubei-adult-category-collection-plans.json` 是院校科类级征集计划。
  湖北征集志愿公告明确只填院校代号、不填专业，禁止将科类人数分摊到具体专业。
  2024 原始科类码 `1213/1214/1215` 与用于系统科类匹配的后两位分别保留。
- `hubei-adult-control-scores.json` 只含专升本省控线，不能当作院校实际录取线。
- 专业科类、学费、教学点没有明确来源则保持空。湖北工程学院的“学科门类”
  保存在 `discipline_raw`，湖北医药学院简章为招生预告；标准考试科类按考试院
  2026专业与统考科目对照表核对，原始科类字段保留为空。湖北中医药大学的应用心理学原文为经济管理类。
- 华中农业大学只保留招生地区含湖北的记录，专业名中的星号/新增标记原文单独保留。
- 湖北大学“高起专、专升本、高起本”分表识别，湖北工程学院“高起本、专升本”
  分表识别，其他表格按原始 `rowspan/colspan` 恢复层次，防止串行和混入其他层次。

## 复现与校验

在服务端目录执行：

```bash
.venv/bin/python -m scripts.scrape_hubei
.venv/bin/python -m unittest tests.test_hubei
.venv/bin/python -m scripts.seed_hubei
.venv/bin/python -m scripts.validate_data
```

默认使用已归档原件；加 `--refresh` 重新下载 `source-urls.json` 内记录的官方资源。
解析器校验每年 8 类控制线，并独立用整份 PDF 文本计数核对征集行数。
`scrape_hubei` 和测试不写业务数据库；`seed_hubei` 在事务内重复执行不产生重复记录。
省级科类征集保存在院校补充数据的独立字段，经独立接口字段和页面展开列表展示，不写入逐专业计划。
`exam-categories-2026.txt` 由官方 DOC 使用 macOS textutil 提取，来源和摘要见清单；DOC变化时需重新提取核验。
