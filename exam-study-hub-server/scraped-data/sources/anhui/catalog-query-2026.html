2026年全国各类成人高校在皖统一招生计划说明

一、2026年全国共有117所各类成人高校在皖招生。

二、招生专业目录公布的收费标准，仅供考生选报学校提供参考，实际收费以当地物价主管部门核定为准，部分未注明收费标准的，可向招生院校咨询。

三、招生范围和专业加试信息栏中：委托培养、定向、直属单位、“一村一名大学生”、煤炭员工单独录取的招生都有具体要求，考生可向相关招生院校咨询。

四、因院校安排业余形式的教学时间不同，考生可与报考院校联系，详细了解院校的教学地点、时间等具体情况，便于妥善安排自己的学习和工作。

五、公布的分学校分专业代码，是考生填报志愿和录取的重要依据之一。报考成人高校详细信息，请考生上网阅读我院公布的“报考须知与问答”和有关成人高校招生文件等资料。
