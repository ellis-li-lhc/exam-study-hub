江西水利电力大学2026年高等学历继续教育招生简章
2026-07-17 21:56     (点击： )

 

一、学校简介

 江西水利电力大学是一所以水利、电力为特色，工学为主、多学科协调发展的高水平教学研究型大学，曾先后隶属水利电力部、水利部，原为水利部四所直属院校之一，现为江西省人民政府与水利部共建高校，是江西省“十四五”博士学位授予单位立项建设单位、国家“卓越工程师教育培养计划”“卓越农林人才教育培养计划”实施高校，是全国48所为军队定向培养军士院校之一。

学校坐拥瑶湖和彭桥两大校区，校舍建筑面积67.38万平方米。学校建设有一支高水平教师队伍，现有教职工1600余人，其中专任教师1200余人，高级专业技术职务教师近500人、博士学位教师近600人。

二、学院概况

江西水利电力大学高等学历继续教育自1987年办学以来，全面贯彻党的教育方针，坚持社会主义办学方向，坚持为党育人、为国育才，紧扣立德树人根本任务，遵循继续教育规律，坚持规范办学与内涵发展，依托学校优质的教育资源和雄厚的师资力量，为国家培养了大批应用型高级工程技术人才和管理人才。

四、招生对象及报考条件

1.招生对象：各类高、中等学校在校生以外的从业人员和社会其他人员。具体要求参照《2026年全国成人高校招生办法》。

2.报考条件：报考高中起点升本科（高起本）或高中起点升专科（高起专）的考生应具备高级中等教育学校、中等职业教育学校毕业或具备同等学力的条件；报考专科起点升本科（专升本）的考生必须取得经教育部审定核准的国民教育系列高等学校、高等教育自学考试机构颁发的专科毕业证书、本科结业证书或以上证书并提供学信网证明材料。

五、报考流程及时间


 1.即日起校本部接受考生预报名，可扫描下方二维码入群咨询。预报名电话：15979110377（微信同号），13397091632，0791-88307340，0791-88307056；

2.正式报名阶段（8月底—9月初）：登录江西省教育考试院官网（http://www.jxeea.cn）点击“服务大厅”→“成人高考网上报名”，进入报名系统，注册并填写报名信息，上传相关材料。待资格审核完成后再次登录报名系统填报学校和专业志愿并进行缴费。

在江西省外其他地区报考的考生，报考流程按当地教育考试管理机构公布的文件执行。

六、收费标准

学费按照赣教计字〔2000〕163号文件公布的收费标准执行，专科学费1400元/人∙学年，本科学费1700元/人∙学年。以物价部门最新核定后的标准执行。

七、优惠政策

1.优秀运动员，参加“选聘高校毕业生到村任职”“三支一扶”(支教、支农、支医和扶贫)“大学生志愿服务西部计划”“农村义务教育阶段学校教师特设岗位计划”等项目服务期满并考核合格、以及应征入伍服义务兵役退役的普通高职（专科）毕业生，退役军人，可申请免试入学就读我校专升本层次专业。

2.年满25周岁以上（2001年12月31日前出生），可以在考试成绩基础上增加20分投档。

其他优惠政策以各地区考试管理机构公布的文件为准。
