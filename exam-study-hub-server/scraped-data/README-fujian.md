# 福建成人专升本数据

已完整抓取2026年11月6日[福建省教育考试院成考招生计划公开查询](https://ckcz.eeafj.cn/ShowReport.wx?PAGEID=pg_tz_enroll_regulations)的25个分页、965条各学历层次记录，筛选并导入其中40所院校、468条专升本记录，去重为242个院校专业组合。其余497条（高起专494条、高起本3条）不会混入专升本库。活动年度以同站首页“2026年福建省成人高校招生全国统一考试”及报名/志愿确认时间核验，保留首页原始响应。

原始表中隐藏td占位符不是数据列：先排除 `display:none` 的单元格，再按真实rowspan展开。每页核对实际页码与固定页长，总数独立对照网页的 `RECORDCOUNT=965`、`PAGECOUNT=25`，同时核对院校/专业编码唯一性，避免把首屏或分页重复当作全量。

采用官方4位招生院校代码及官方4位专业编码；不能将其当作教育部国家代码。包含在福建招生的省外院校，校本部城市按教育部学校名单核验，福建教育学院和福建开放大学按教育厅章程或学校地址核验。授课地点、收费标准、专业备注分别保留。不同教学点保持不同专业编码，不合并丢失条件。目录未公布招生人数，`plan_count=null`；结构化收费金额只接受明确的每年/每学年口径。例如“1680元”保持原文，金额和计费单位均未知，并提示不得当作年学费。

10条在职消防人员限定、农业委培等不面向普通社会考生的记录标记 `selection_eligible=false`；原始资料保留，但普通备考目标、教学点及学费汇总均排除。医学等专业仍需依当年资格要求核验，不构成报考资格或录取承诺。

2025专升本省控线8条来自考试院[原始公告](https://www.eeafj.cn/ckgsgg/20251124/14351.html)及其图片，按原始图片目视核对，保留绑定SHA-256的 `controls-2025-reviewed.json`。排除原图高起本259/118分、高起专100/100分；专升本文史中医151、艺术109、理工100、经管100、法学100、教育160、农学104、医学160分。没有院校实际录取线，不用省控线推导院校提分目标。2026控制线和2027专业目录尚未收录，2026目录用于2027备考仅作历史参考。

2025征求志愿公告只有院校剩余计划总数，未明示专业及科类。本次保留原始公告供核对，不把院校总人数分配给专业，也不将变动的2025招生院校代码直接当作2026代码关联。
