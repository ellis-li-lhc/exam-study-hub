# 安徽成人专升本数据

已完整抓取2026年11月6日[安徽省成人高校招生网公开专业查询](https://crbm.ahzsks.cn/enrollMajor)中“专升本”筛选结果的37个分页：71所院校、1104条专业/教学点记录、485个院校专业组合。与查询页面独立公布的1104条总数、分页标记和去重键逐项核对，未把学校目录117校（含其他学历层次）当作专升本院校总数。

招生省份表示“在安徽招生”，包括省外学校。院校代码取官方3位招生编码；5位院校专业代码保留原文，不推定为国家本科专业代码。城市按教育部2026学校名单或安徽开放大学官方地址核验；城市为校本部所在地，不能替代具体专业的教学点。招生范围及加试信息完整保存在备注中，原文明确提及教学点、校本部或校区的才填入教学点字段。

目录没有公布人数，`plan_count=null`，`line_type=招生专业目录`；学制、费用与条件逐条保留。金额没有计费周期或格式不明确时，保留收费原文并保持结构化金额/单位未知，不猜测年学费。原文21条专项限定记录标记 `selection_eligible=false`，普通学习目标、专业详情和费用汇总均排除；明确写“社会招生或面向一村一名大学生”的记录仍保留普通报考资格。

另收录安徽科技工程大学继续教育学院官网转载的2024、2025专升本省控线，每年8科类，共16条；原始公告含高起本/高起专分数，解析时排除。没有院校实际录取分数线，不以省控线生成院校提分目标。2026录取控制线和2027目录尚未收录，2026目录用于2027备考时仅作历史参考。

省教育厅[常见问题解答及附件](https://jyt.ah.gov.cn/tsdw/gdjyc/tzgg/40798706.html)中的省属高校备案Excel及教学点名单同时归档，不与公开查询结果重复入库；备案“最低修业年限”不能覆盖招生目录的“学制”。

原始响应位于 `sources/anhui/`，每页请求体保存在 `source-requests.json`，URL在 `source-urls.json`，哈希和公开总数在 `anhui-manifest.json`。网站表单通过POST传递分页参数，GET附加页码会仍显示第一页；抓取器核对实际页码及全部37页。部分响应的移动端重复布局在尾部截断，桌面主表完整闭合；解析只使用完整主表并禁止其单元格含替代字符，总数仍须等于1104，不能把截断响应当作下一页。

不新增数据库表，沿用 `institutions`、`admission_plans`、`province_control_scores` 及既有JSON详情字段；进口仅作用于安徽/福建，可重复执行，不删除或重建其他省份。

在后端目录执行：

```sh
.venv/bin/python -m scripts.scrape_anhui_fujian # 离线重放；--refresh重复公开表单请求
.venv/bin/python -m scripts.seed_anhui_fujian # 两省统一事务导入
.venv/bin/python -m scripts.validate_data
.venv/bin/python -m unittest tests.test_anhui_fujian
```

主初始化脚本 `python -m scripts.seed` 已接入这两个省份。当前仅入本地系统，尚未推送部署至远程生产环境。
